# marketing-course

A 24-week, hands-on marketing program for technical founders who need to market a software platform.

Start here: [marketing-program/README.md](marketing-program/README.md)

- `marketing-program/` contains the curriculum: one file per week (`week-01.md` to `week-24.md`) plus the diagrams in `images/`.
- `scripts/make_diagrams.py` regenerates the framework diagrams.
- `scripts/check_links.py` verifies every link in the program from a machine with internet access.
